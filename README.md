# scientific_calculator-
A simple interactive command line Scientific Calculator built using python's in-built math module.

## Features

- **Basic Arithmetic:** Addition (`+'), Subtraction (`-`), Multiplication (`*`), Division (`/`)
- **Trigonometry:** Sine (`sin`), Cosine (`cos`), Tangent (`tan`) in radians
- **Log & Exponential:** Logarithm (`log`), Exponential (`exp`)
- **Powers & Roots:** Power (`pow`), Square Root (`sqrt`), Cube Root (`cbrt`)

## Requirements

- Python 3.11 or higher

## How to Run

1. Download or copy the `Vityarthi Project CSE1021.py` file to your computer.
2. Open your terminal or command prompt in that folder.
3. Run the script:

python Vityarthi Project CSE1021.py

## Example Usage

Available Operations are: 
1. + for addition
2. - for subtraction
3. * for multiplication
4. / for division 
5. sin for sine(in radians)
6. cos for cosine(in radians)
7. tan for tangent(in radians)
8. log for logarithm 
9. exp for exponential
10. sqrt for square root
